## ⚡ How to Run Locally or Deploy

### Run Locally:
Just double-click `index.html` in any web browser! No bundlers, Node packages, or setup required.

Or run a quick local server with Python or Node:
```bash
# Using Python
python -m http.server 8000

# Using Node (npx)
npx serve
```

### Deploy in 30 Seconds:
- **GitHub Pages:** Push this repository to GitHub and enable GitHub Pages in Settings -> Pages -> Deploy from branch `main` / root.
- **Vercel / Netlify:** Import the GitHub repo and hit Deploy!
